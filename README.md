# My Bloody Harmonia

Слухає гру через мікрофон, розпізнає акорди в реальному часі й показує на кварто-квінтовому колі, куди піти далі. Підказки є для гітари, баса, клавіш і соло.

**Розпізнає:** мажор, мінор, `7`, `maj7`, `m7`, `sus2`, `sus4`, `dim`, `dim7`, `aug`, `5` (пауер-акорд).

## Запуск

Потрібен Python 3.10+ і мікрофон.

```bash
pip install -r requirements.txt
python -m harmonia.server
```

Браузер відкриється сам на `http://127.0.0.1:8000`. Перші ~1 секунду мовчіть: програма вимірює шум кімнати.

Якщо вибрався не той мікрофон:

```bash
python -m harmonia.run_live --list          # список пристроїв
python -m harmonia.server --device N        # N з цього списку
```

## Корисні параметри

| Параметр | Що робить | За замовчуванням |
|---|---|---|
| `--device N` | номер мікрофона | системний |
| `--port N` | порт сайту | 8000 |
| `--gate X` | фіксований поріг тиші (інакше автокалібрування) | авто |
| `--thresh X` | мін. схожість із акордом | 0.75 |
| `--coverage X` | мін. присутність нот акорду (відсікає голос) | 0.40 |
| `--ext X` | мін. присутність 7-ї ноти | 0.40 |
| `--no-browser` | не відкривати браузер | |

Щоб побачити, що саме чує програма, запустіть консольну версію з діагностикою: `python -m harmonia.run_live --debug`.

## Якщо щось не працює

- **Програма реагує на голос, а гітару не чує.** Вимкніть шумозаглушення мікрофона (Windows: *Параметри → Звук → Вхід → Властивості → Покращення звуку*, або «Voice Focus» / «AI noise cancellation» в аудіопанелі ноутбука). Спрямуйте мікрофон на комбік або гітару.
- **Акорд «стрибає».** Підніміть `--coverage` (наприклад 0.5) або зіграйте голосніше.
- **Септакорди плутаються з тризвуками.** Зменште `--ext` (наприклад 0.3).
- **Довгий перший запуск на Windows.** `scipy` і `numpy` у перший раз імпортуються повільно (антивірус); далі швидше.

## Структура

```
harmonia/
  dsp/       chroma.py, chords.py, smoother.py      # FFT → chroma → акорд → стабілізація
  io/        mic_source.py, wav_source.py           # мікрофон (кільцевий буфер) і WAV
  theory/    circle.py, instruments.py              # коло квінт, тональність, поради
  engine.py  server.py  run_live.py                 # конвеєр, веб-сервер, консольний режим
  ui/        index.html                             # інтерфейс (один файл)
```
